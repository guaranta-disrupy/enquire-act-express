## Variables API

- **Purpose**: Describe how runtime variables are managed and exposed through the API.
- **Scope**:
  - Endpoints for listing, creating, updating, copying, and deleting variables.
  - Variable criteria definitions and how they map URL parameters to variable values.
  - Any helper endpoints used by overlays or external tooling to fetch variable metadata.
- **Conventions**:
  - Keep examples aligned with the engine’s variable resolution logic (`getVariables`, criteria).
  - For each endpoint, include example criteria blocks and the resulting variable payloads.
