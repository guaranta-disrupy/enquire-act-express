## Templates API

- **Purpose**: Capture all endpoints for managing reusable primes/targets and other survey templates.
- **Scope**:
  - CRUD operations for template primes and template targets.
  - Copy/duplicate flows and relationships to surveys/tests.
  - Any bulk import/export or synchronization APIs.
- **Conventions**:
  - Use the same field names and structures as the survey editor (prime config, target config).
  - Highlight how template APIs should be used from tooling or automation (not end-respondents).
